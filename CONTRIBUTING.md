# Contributing to ThermoShift

Thank you for contributing to **ThermoShift**!

---

## 🛠️ Development Setup

1. **Clone Repo:**
   ```bash
   git clone https://github.com/HAFIZ-HAASHIM/thermoshift.git
   cd thermoshift
   ```

2. **Backend & Optimizer Setup:**
   ```bash
   cd backend
   python -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   pytest
   ```

3. **Frontend Setup:**
   ```bash
   cd ../frontend
   npm install
   npm run dev
   ```
